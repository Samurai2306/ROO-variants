# v3 — Технический

Макет будущего сайта РОО ветеранов метрологической службы. Направление: «Технический».

Откройте `index.html`. Стили и сценарий лежат рядом: `styles.css`, `script.js`.

Страницы: главная, новости, запись, партнёры, карточка партнёра, об организации, деятельность, наследие, издания, контакты, регистрация, профиль, форум, ветка и закрытая ветка. Приёмная: Страница `reception.html`.

Меню на узкой ширине закрывается клавишей Escape. Окна закрываются кнопкой «Закрыть», Escape и щелчком по затемнению. Каталог умеет пустой результат. Верная форма показывает «Демонстрационный режим: данные не отправлены» и ничего не отправляет.

Знаки действий — фрагменты SVG Themify Icons. Логотип Themify и чужие бренды не используются. «Гимн» не воспроизводит звук. Регистрация на макете не создаёт учётную запись.

Перенос на 1С-Битрикс в этот каталог не входит.
